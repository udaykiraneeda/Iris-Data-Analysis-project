# 🌸 Codveda Technology — Data Analytics Internship

This repository contains all the tasks completed as part of the **Data Analytics Internship** at [Codveda Technology](https://www.codveda.com), using the classic **Iris dataset**.

Across three levels, I worked through the full data analytics pipeline — from raw data cleaning to machine learning and an interactive dashboard.

---

## 📁 Repository Contents

| File | Level | Description |
|---|---|---|
| `Iris_Task_1_Data_Cleaning_and_Preprocessing.ipynb` | Level 1 (Basic) | Loaded the raw dataset, handled duplicates, and standardized data formats using pandas |
| `Irisi_Level_2_Exploratory_Data_Analysis__EDA_.ipynb` | Level 1 (Basic) | Summary statistics, distributions, and correlation analysis using matplotlib & seaborn |
| `Level_3_Predictive_Modeling__Classification_.ipynb` | Level 3 (Advanced) | Trained and compared Logistic Regression, Decision Tree, and Random Forest classifiers; tuned with GridSearchCV |
| `uday_2.pbix` | Level 3 (Advanced) | Interactive Power BI dashboard with KPI cards, scatter/bar charts, and species slicer |

## 📊 Project Highlights

### Level 1 — Data Cleaning & EDA
- Removed duplicate rows and standardized categorical/numeric formats
- Explored feature distributions and correlations across the dataset

### Level 2 — Regression & Clustering
- Built a linear regression model (R² = 0.94) to predict petal length from petal width
- Applied K-Means clustering, validated with the elbow method

### Level 3 — Classification & Dashboard
- Compared 3 classification models; tuned **Random Forest** reached **96.7% accuracy** predicting iris species
- Built an interactive Power BI dashboard with filters, KPI cards, and linked visualizations

---

## 📌 About the Dataset

The [Iris dataset](https://archive.ics.uci.edu/dataset/53/iris) contains 150 flower samples across 3 species (*setosa*, *versicolor*, *virginica*), with 4 measurements each: sepal length, sepal width, petal length, and petal width.
